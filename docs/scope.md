# Alcance

## MVP

- Android.
- Análisis manual de enlaces.
- Análisis automático de links recibidos desde otras aplicaciones.
- Estados `SAFE`, `SUSPICIOUS` y `DANGEROUS`.
- Bloqueo de enlaces peligrosos.
- WebView protegido.
- Historial local.
- Ayuda educativa.
